# NumberLab games

Games live in `public/numbers/games/<slug>/`. Dino Egg Rescue lives in `dino-egg-rescue/` with `index.html`, `game.css`, and `game.js`. It uses the pure counting engine, shared tier definitions, adaptation, and the single `nl_v1` progress record. Play five silent visual challenges per round, from counting eggs to regrouping tens. Rocket Fuel lives in `rocket-fuel/` with the same three-file layout and uses `engine/addition.js` plus the counting engine’s dot patterns. Its five-challenge rounds cover combining fuel, filling to a target, number bonds, tens-and-ones building, mental addition, and balanced sums. Both games adapt independently and save only first submissions. The other three games remain coming soon.
